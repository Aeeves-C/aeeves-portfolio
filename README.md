# Aeeves Chan — Engineering Portfolio

Personal engineering portfolio: aerospace and mechanical projects, work
experience, and leadership roles.

Single-file static site (self-contained `index.html`), no build step,
no dependencies.

## Deploy

Connected to Vercel. Every push to `main` auto-deploys. No framework
preset, no build command, no environment variables needed.

## Update the live site

Replace `index.html` with the new version, then:

    git add -A
    git commit -m "Update portfolio content"
    git push
